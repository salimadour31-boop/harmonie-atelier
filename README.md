# Harmonie Atelier

Générateur de palettes de couleurs harmonieuses, 100 % dans le navigateur.

Idéal pour graphistes, designers UI et cinéastes qui veulent des palettes cohérentes, accessibles et prêtes pour le web ou l’image.

## Démo

👉 [https://salimadour31-boop.github.io/harmonie-atelier/](https://salimadour31-boop.github.io/harmonie-atelier/)

## Fonctionnalités

- Génération selon les règles d’harmonie (analogue, complémentaire, triadique, split, tétradique, monochromatique)
- Extraction de couleurs dominantes depuis une image (tout se passe localement)
- Aperçu live sur une carte UI et un cadre cinématique
- Vérification du contraste WCAG (AA / AAA)
- Export CSS variables, JSON, PNG de la palette
- Multilingue : français, anglais, tamazight (Taqbaylit)
- Thème sombre, interface claire et responsive
- Aucune donnée n’est envoyée : tout reste dans votre navigateur

## Usage

1. Choisissez une couleur de base ou chargez une image.
2. Sélectionnez le type d’harmonie et cliquez sur Générer.
3. Cliquez sur une couleur pour la copier ou la verrouiller.
4. Exportez selon vos besoins.
